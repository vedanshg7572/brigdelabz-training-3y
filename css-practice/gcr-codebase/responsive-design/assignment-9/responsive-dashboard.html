CSS Filters

Filters let you apply visual effects like blur, grayscale, sepia and brightness to images and elements in CSS.

Typography

Responsive typography uses clamp() and viewport units like vw to make font sizes adjust automatically with screen size.

Media Queries

Media queries let you apply different CSS styles based on screen width, height, and device type using @media rule.

Cheat Sheet

Key responsive CSS tools: flex-wrap, auto-fit, minmax(), clamp(), grid-template-areas, and @media breakpoints.
