About Responsive Design

Responsive design makes websites look good on all screen sizes. It uses media queries, flexible units, and Flexbox or Grid layouts to adjust the page based on the device width.

Key tools: clamp(), vw/vh units, auto-fit grids, and flex-wrap. When you resize your browser, everything adjusts automatically.

Quick Cheat Sheet

  • filter: grayscale, blur, sepia, brightness
  • clamp(): min, preferred, max font size
  • @media: apply styles at breakpoints
  • flex-wrap: wraps items to next row
  • auto-fit: auto column count in grid
