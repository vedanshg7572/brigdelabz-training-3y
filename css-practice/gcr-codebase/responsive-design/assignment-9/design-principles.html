Core Principles of Responsive Design

Fluid Layouts

Fluid layouts use percentage-based widths instead of fixed pixels. This means the layout stretches or shrinks to fit the available screen space.

width: 100%;
max-width: 1200px;
margin: 0 auto;

Flexible Media

Images and videos should resize with the layout. Using max-width: 100% ensures media never overflows its container.

img {
  max-width: 100%;
  height: auto;
}

Breakpoints

Breakpoints are specific screen widths where the layout changes. We use media queries to apply different CSS rules at each breakpoint.

@media (max-width: 768px) {
  .container {
    flex-direction: column;
  }
}
