Box-Sizing Comparison

Default (content-box)

width: 300px + padding: 30px = total width is 360px

In default box-sizing, padding is added on top of the width. So the actual size becomes larger than what you set.

border-box

width: 300px including padding = stays at 300px

With border-box, the padding is counted inside the width. The total size stays exactly as you set it.
