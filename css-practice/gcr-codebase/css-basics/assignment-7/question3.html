Gradient Backgrounds Demo

Linear Gradient

This section uses a linear gradient background that goes from left to right. Linear gradients go in a straight line from one color to another. I used the CSS property background: linear-gradient() to create this.

Fixed Background - Parallax Effect

This section uses background-attachment: fixed which creates a parallax-like effect when you scroll the page. The background image or color stays fixed while the content scrolls over it.

Radial Gradient

This section uses a radial gradient that starts from the center and spreads outward in a circular pattern. Radial gradients are good for creating spotlight or glow effects.
