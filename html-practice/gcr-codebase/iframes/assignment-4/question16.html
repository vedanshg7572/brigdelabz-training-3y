URI Encoding Demo

Wrong URL (not encoded):

https://example.com/search?query=HTML & CSS

Correct Encoded URL:

https://example.com/search?query=HTML%20%26%20CSS

Why URI Encoding is Important

URLs can only contain certain safe characters. Special characters like spaces, &, =, and # have special meaning in URLs. So we need to encode them using percent encoding. For example a space becomes %20 and & becomes %26. This makes sure the URL is read correctly by the browser and server.

Common Encoding Examples

Space = %20

& = %26

= (equals) = %3D

? (question mark) = %3F

# (hash) = %23
