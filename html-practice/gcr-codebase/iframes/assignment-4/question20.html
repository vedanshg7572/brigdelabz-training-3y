All Important HTML Head Elements

This page shows the use of all important tags that go inside the head section of an HTML page.

  • title - Sets the name shown on the browser tab
  • meta charset - Tells the browser to use UTF-8 encoding
  • meta description - A short description for search engines
  • meta author - Name of the person who made the page
  • base - Sets the default base URL for all links
  • link - Used to connect external files like favicon
  • style - Used to write CSS inside the HTML file
  • script - Used to write or link JavaScript
