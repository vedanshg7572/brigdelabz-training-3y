Q2. Create a simple diagram showing how the client-server model works in web architecture.

Client-server model means one computer sends a request and another computer gives a response.

The client is my browser. The server is the computer where the website is stored.

Example - I open my browser and type www.youtube.com. My browser is the client. It sends a request to YouTube server. The YouTube server gets my request and sends back the YouTube homepage. My browser shows me the page.
