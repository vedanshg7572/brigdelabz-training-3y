Q9. Research and list five web browsers. Explain how rendering engines differ between them.

A web browser is a software that I use to open and view websites. Different browsers use different rendering engines. A rendering engine reads the HTML and CSS code and converts it into the page that I see on the screen.

Five Web Browsers:

1. Google Chrome

Google Chrome is made by Google. It is the most popular browser in the world. It uses a rendering engine called Blink. It is very fast and supports all modern web features.

2. Mozilla Firefox

Firefox is made by Mozilla. It is an open source browser. It uses a rendering engine called Gecko. Firefox is known for its privacy features and good developer tools.

3. Microsoft Edge

Edge is made by Microsoft. Earlier it had its own engine called EdgeHTML but now it uses Blink, same as Chrome. It comes pre-installed on Windows computers.

4. Apple Safari

Safari is made by Apple. It is the default browser on iPhones and Macs. It uses a rendering engine called WebKit. It is very fast on Apple devices and uses less battery.

5. Opera

Opera is a browser that also uses the Blink engine now. It has some extra built-in features like a free VPN and an ad blocker.

How rendering engines differ:

Each browser uses a different rendering engine. Chrome and Edge use Blink. Firefox uses Gecko. Safari uses WebKit. Because of these different engines, sometimes the same website can look slightly different in different browsers. Some CSS properties may work in Chrome but not look the same in Firefox or Safari. That is why web developers test their websites on multiple browsers to make sure everything looks correct everywhere.
