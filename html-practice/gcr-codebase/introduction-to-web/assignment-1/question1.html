Q1. Difference between frontend, backend, and full-stack development.

Frontend Development

Frontend development is the part of a website that we can see on the screen. Like buttons, images, text, and colors. I use HTML, CSS, and JavaScript for frontend.

Example - When I open Amazon, I can see the products, search bar and cart button. That is frontend.

Backend Development

Backend development is the part that runs behind the screen. The user cannot see it. It handles things like saving data, login, and orders. I use Node.js or Python for backend.

Example - When I click on Buy Now on Amazon, the backend saves my order in the database.

Full Stack Development

A full stack developer does both frontend and backend work. He can make a complete website alone.

Example - If I make a complete website like Swiggy on my own, from design to database, then I am a full stack developer.
