Q4. Identify and list the tools required to set up a web development environment. Explain the purpose of each.

To start web development I need some tools. Here is the list:

1. VS Code (Visual Studio Code)

VS Code is a code editor. I write my HTML, CSS, and JavaScript code in it. It has many helpful features like auto-complete and extensions.

2. Google Chrome Browser

I use Chrome to open and test my web pages. It also has DevTools which helps me check errors and see how my page looks.

3. Git

Git is a tool to save and track my code changes. If I make a mistake I can go back to the previous version of my code.

4. GitHub

GitHub is a website where I upload my code online. My teacher or mentor can see my code there. It also helps in team projects.

5. Node.js

Node.js lets me run JavaScript on the server. It also comes with npm which I use to install extra packages and libraries.

6. Live Server Extension

Live Server is a VS Code extension. When I save my HTML file it automatically refreshes the browser. So I don't have to manually reload every time.

7. Terminal

Terminal is a command line tool. I use it to run Git commands, start servers, and install packages.
