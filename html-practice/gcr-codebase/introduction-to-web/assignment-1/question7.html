Q7. Install VS Code and configure it for HTML, CSS, and JavaScript development.

I installed VS Code from the official website which is code.visualstudio.com. I downloaded the Windows version and ran the installer. During installation I selected the option to add VS Code to PATH so I can open it from the terminal also.

Extensions I installed for web development:

  1. Live Server - This extension automatically refreshes my browser when I save my HTML file. So I don't have to reload the page manually every time.
  2. Prettier - Code Formatter - This extension automatically formats my code and makes it clean and readable whenever I save the file.
  3. HTML CSS Support - This gives me suggestions for CSS class names while writing HTML code.
  4. Auto Rename Tag - When I change the opening HTML tag it automatically changes the closing tag too.
  5. JavaScript ES6 Snippets - This gives me short code shortcuts for writing JavaScript faster.

Settings I configured:

  1. I set Prettier as the default code formatter.
  2. I turned on Format on Save so my code gets formatted automatically every time I save.
  3. I increased the font size to 14 for better readability.
  4. I enabled word wrap so long lines don't go off screen.

After installing and setting up everything I opened a sample HTML file and tested it with Live Server. It worked correctly and the browser opened and showed my page automatically.
