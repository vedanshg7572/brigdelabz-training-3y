Q6. Define the roles of a frontend developer, backend developer, and database administrator in a project.

Frontend Developer

A frontend developer makes the part of the website that users see on the screen. He designs the layout, adds buttons, images, text, and makes sure the website looks good on all devices. He uses HTML, CSS, and JavaScript.

Example - In a project like Zomato, the frontend developer makes the homepage, the food menu page, and the order tracking screen.

Backend Developer

A backend developer builds the logic that runs behind the website. He makes APIs, handles user login, processes orders, and connects the frontend to the database. He uses Node.js, Python, or Java.

Example - In Zomato, the backend developer writes the code that saves your order, checks your payment, and assigns a delivery person.

Database Administrator (DBA)

A database administrator manages the database. He makes sure all the data is stored safely and can be retrieved quickly. He also takes backups and manages who has access to the data. He uses MySQL, MongoDB, or PostgreSQL.

Example - In Zomato, the DBA manages the database that stores all user details, restaurant menus, and order history.
