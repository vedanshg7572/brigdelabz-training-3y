Q5. Explain what a web server is and give examples of commonly used servers.

A web server is a computer that stores website files and sends them to users when they request it. When I type a website URL in my browser, my browser asks the web server to give that website. The server then sends back the HTML, CSS, and other files and my browser shows me the website.

Web servers use HTTP or HTTPS protocol to communicate with browsers.

Examples of commonly used web servers:

1. Apache HTTP Server

Apache is one of the most popular web servers. It is free and open source. Many websites on the internet use Apache.

2. Nginx

Nginx is a fast web server. It can handle many users at the same time. It is also used as a reverse proxy.

3. Microsoft IIS

IIS stands for Internet Information Services. It is made by Microsoft and is used on Windows computers.

4. Node.js with Express

Node.js with Express framework can also work as a web server. Many developers use it to build backend applications.

5. LiteSpeed

LiteSpeed is a fast web server. It is mostly used by hosting companies. It is faster than Apache in many cases.
