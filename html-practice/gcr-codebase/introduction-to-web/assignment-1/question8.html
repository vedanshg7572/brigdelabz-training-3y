Q8. Explain the difference between static and dynamic websites. Provide an example of each.

Static Website

A static website shows the same content to every user. The pages are already made and do not change. The developer writes the HTML and CSS files and uploads them. When anyone opens the website they see the same thing. There is no database and no server-side programming needed.

Example - A personal portfolio website. My portfolio page shows the same information like my name, skills, and projects to everyone who visits it. The content does not change based on who is visiting.

Dynamic Website

A dynamic website shows different content to different users. The content is generated by the server based on who is logged in or what they searched for. It uses a database to store data and server-side languages like PHP, Node.js, or Python to process requests.

Example - Facebook is a dynamic website. When I log in to Facebook I see my own posts, my friends, and my notifications. When my friend logs in he sees his own feed. The content is different for every user.

Main Differences

  • Static websites show the same content to everyone. Dynamic websites show different content based on the user.
  • Static websites are faster. Dynamic websites are a bit slower because they process data before showing the page.
  • Static websites are cheaper to host. Dynamic websites need more resources.
  • Static websites are used for simple pages. Dynamic websites are used for apps like YouTube, Amazon, and Instagram.
