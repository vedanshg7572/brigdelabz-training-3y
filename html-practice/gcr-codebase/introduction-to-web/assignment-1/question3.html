Q3. Describe how a browser requests and displays a web page from a web server.

When I type a URL in the browser and press Enter, these steps happen:

  1. I type the URL like www.google.com in the browser and press Enter.
  2. The browser first contacts a DNS server. DNS converts the website name into an IP address like 142.250.194.46 so the browser knows where to go.
  3. The browser connects to the server at that IP address.
  4. The browser sends an HTTP request to the server asking for the web page.
  5. The server gets the request and sends back the HTML, CSS, and JavaScript files.
  6. The browser reads those files and shows the web page on my screen.

Example - When I open Instagram, my browser finds Instagram's server, asks for the homepage, and the server sends back all the files. Then my browser shows me the Instagram feed.
