Q10. Draw a labeled diagram showing the basic web architecture flow - client, server, database, and APIs.

Explanation of each part:

Client

The client is my browser or mobile app. When I open a website or press a button, the client sends a request to the server.

Web Server

The web server receives the request from the client. It processes it and either sends back a web page directly or calls an API to get data.

API

API stands for Application Programming Interface. It is like a middleman between the server and the database. The server asks the API for data. The API gets that data from the database and sends it back.

Database

The database stores all the information like usernames, passwords, products, and orders. When the API asks for data, the database gives it back.

Example:

When I search for shoes on Amazon, my browser sends a request to Amazon's server. The server calls the API. The API gets the list of shoes from the database. The database sends the data back to the API. The API sends it to the server. The server sends it to my browser. My browser shows me all the shoe results on the screen.
